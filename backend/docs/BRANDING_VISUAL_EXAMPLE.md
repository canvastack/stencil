## Example Configuration Result

With this configuration:
```env
BRANDING_COMPANY_NAME="PT Custom Etching Xenial"
BRANDING_TAGLINE="Excellence in Custom Etching Solutions"
BRANDING_PRIMARY_COLOR="#4F46E5"
```

You get:
```
╔════════════════════════════════════════════════════════════════╗
║                    [Your Logo Image]                           ║
║                                                                ║
║              PT CUSTOM ETCHING XENIAL                          ║
║          Excellence in Custom Etching Solutions                ║
║                                                                ║
║  [All contact information and document details follow]         ║
╚════════════════════════════════════════════════════════════════╝
```
